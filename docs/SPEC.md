# ТЗ: прототип голосового ассистента (сводка)

Сводка исходного тестового задания. Оригинал (PDF) хранится у участников локально и в репозиторий
не коммитится.

## Суть

Ассистент помогает управлять личными задачами, напоминаниями и встречами с помощью естественной
речи. Ввод — голосом и текстом, в свободной форме; ответ — голосом или текстом. Акцент на логике
(понимание запроса, работа с данными, корректное выполнение), а не на интерфейсе.

## Сценарии

### 1. Создание задачи / напоминания
- «Напомни мне завтра в 10 утра позвонить Ивану»
- «В пятницу нужно отправить отчёт»
- «Поставь задачу купить билеты до конца недели»

Определить содержание, дату и время (если указаны), сохранить, подтвердить пользователю.

### 2. Создание встречи
- «Добавь встречу с командой завтра в 15:00»
- «В четверг в 11 у меня встреча с дизайнером»

Определить название/содержание, дату и время, сохранить.

### 3. События за период
- «Что у меня сегодня?», «Есть ли у меня встречи сегодня?»
- «Какие задачи у меня на завтра?», «Что запланировано на эту неделю?»

Найти события и сформировать понятный ответ.

### 4. Поиск старых записей
- «Найди задачу про презентацию»
- «Когда у меня была встреча с Иваном?»
- «Я когда-то ставил задачу по договору, найди её»

Точное совпадение формулировок не требуется; желателен поиск по близким по смыслу запросам.

## Естественный язык
- Без фиксированных команд: «Что у меня сегодня?», «Какие планы на сегодня?», «Покажи мои встречи
  на сегодня» — одно и то же действие.
- Относительные даты: сегодня, завтра, послезавтра, в пятницу, через два часа, на следующей неделе.
- При нехватке данных — уточняющий вопрос. Пример: «Поставь встречу с Иваном завтра» → «На какое
  время поставить встречу?»

## Хранение
Для каждой записи как минимум: тип (задача / встреча / напоминание), название или текст, дата и
время, дата создания, статус выполнения (при необходимости). Способ хранения — на выбор.

## Голосовой интерфейс
Цепочка: голос → распознавание речи → обработка запроса → выполнение действия → ответ.
Можно использовать готовые API/библиотеки для STT, TTS и LLM. Достаточно страницы с кнопкой записи,
историей диалога и ответом.

## Обязательный результат
- [ ] создание задачи / напоминания
- [ ] создание встречи
- [ ] список задач и встреч за указанный период
- [ ] поиск ранее созданной задачи или встречи по запросу
- [ ] данные сохраняются между запросами

## Выбираем сами
Язык и стек, LLM, STT/TTS, БД, архитектуру, способ поиска, формат UI. AI-инструменты разрешены.

## Дополнительно (плюс, не обязательно)
- [ ] изменение и удаление задач голосом
- [ ] отметка задачи выполненной
- [ ] обработка конфликтующих встреч
- [ ] повторяющиеся задачи и встречи
- [ ] контекст диалога («А перенеси её на завтра»)
- [ ] семантический поиск по старым задачам
- [ ] интеграция с реальным календарём
- [ ] поддержка нескольких пользователей
- [ ] обработка неоднозначных запросов и уточняющий диалог

## Критерии оценки
- **Работоспособность** — стабильность основных сценариев.
- **Понимание запросов** — естественные формулировки, а не жёсткие команды.
- **Архитектура** — разделение голоса, LLM, бизнес-логики и хранения.
- **Работа с данными** — корректность создания, получения и поиска.
- **Качество кода** — структура, читаемость, обоснованность решений.
- **UX** — естественность диалога, в том числе когда ассистенту не хватает информации.

# Горький — голосовой планировщик задач и встреч

Telegram-бот, который по свободной речи — голосом или текстом — создаёт задачи, напоминания и встречи,
показывает планы на любой период и находит старые записи по смыслу.

**Попробовать:** [@gorky_audio_bot](https://t.me/gorky_audio_bot) → `/start` → в меню «📥 Демо-данные из задания»
загрузит 1000 записей из CSV тестового задания, чтобы сразу проверить поиск и списки.

## Что умеет

| Сценарий | Пример |
|---|---|
| Задача / напоминание | «Напомни завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт» |
| Встреча | «В четверг в 11 у меня встреча с дизайнером» — с предупреждением о пересечениях |
| Планы за период | «Что у меня сегодня?», «Какие задачи на завтра?», «Что запланировано на неделю?» |
| Поиск по смыслу | «Найди задачу про презентацию», «Когда у меня была встреча с Иваном?» |
| Уточнения | «Поставь встречу с Иваном завтра» → «На какое время поставить встречу?» |
| Изменения | «Перенеси её на пятницу», «Переименуй в …», «Я купил билеты», «Встреча отменилась» |
| Повторы | «Каждый понедельник в 10 планёрка», «Напоминай каждый день в 22:00» |

А ещё: напоминания приходят сами (с кнопками «+10 мин / +1 час / Готово»), утренняя сводка,
часовые пояса, голосовые ответы, кнопка «Вернуть» после удаления, Mini App-календарь внутри Telegram
и подписка на календарь телефона (iPhone / Google) в одно нажатие.

## Архитектура

```
голос (ogg) ─► speech/  ─► текст ─► assistant/ ─► llm/ (GigaChat: выбор функции + аргументы)
                                        │
                                        ▼
                              core/ (даты, повторы, проверки) ─► storage/ (PostgreSQL)
                                        │
                     ответ ◄────────────┘   bot/ (Telegram)   webapp/ (Mini App, .ics)
```

| Слой | Модуль | Ответственность |
|---|---|---|
| Интерфейс | `app/bot/` | aiogram 3: панель-меню, кнопки, голосовые, фоновые напоминания и сводка |
| Голос | `app/speech/` | распознавание — GigaChat (аудио), озвучка — edge-tts |
| Диалог | `app/assistant/` | история, контекст («перенеси **её**»), уточняющие вопросы, выполнение действий |
| LLM | `app/llm/` | интерфейс `LLMClient` + реализация GigaChat, описания функций |
| Логика | `app/core/` | относительные даты, повторы, оформление ответов, экспорт iCalendar |
| Данные | `app/storage/` | SQLAlchemy 2 (async) + Alembic, полнотекстовый поиск Postgres |
| Поиск | `app/search/` | если полнотекстовый поиск пуст — GigaChat выбирает подходящие записи |
| Веб | `app/webapp/` | Mini App-календарь, страница подписки, `.ics`-лента (aiohttp, проверка initData) |

**Принцип:** модель не пишет в базу сама. Она выбирает функцию (`create_event`, `list_events`,
`search_events`, `update_event`, …) и заполняет аргументы, а код проверяет их и выполняет действие.

## Технологии и решения

- **Telegram-бот вместо веб-страницы** — голосовые есть «из коробки», ссылка на бота = рабочий прототип,
  пользователь Telegram = отдельный аккаунт (поддержка нескольких пользователей).
- **GigaChat-3-Pro** — сильный русский язык, function calling и распознавание аудио одним ключом.
  Выбор модели — по замерам на наборе фраз (`scripts/eval_phrases.py`): 35/37 фраз, Lightning — 18/20 на базовом наборе.
- **Даты считает код, а не модель.** Модель возвращает «завтра», «четверг», «через 2 часа», «конец недели»;
  точную дату вычисляет `core/dates.py`. Так исчезли ошибки вида «четверг → суббота».
- **Поиск по смыслу без платных эмбеддингов:** сначала полнотекстовый поиск Postgres с русской морфологией
  («договору» → «договор»), сначала записи со всеми словами, ближайшие к сегодня; если пусто — GigaChat
  выбирает из последних записей («Ваня» → «Встреча с Иваном»).
- **PostgreSQL** — данные переживают перезапуски и деплой.
- **Озвучка edge-tts** — SaluteSpeech для физлиц закрыт с 15.07.2026; при сбое бот отвечает текстом.

## Запуск локально

Нужны Python 3.12+, PostgreSQL 16, токен бота от @BotFather и ключ GigaChat API.

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements-dev.txt   # Linux/macOS: .venv/bin/
cp .env.example .env            # заполнить BOT_TOKEN, GIGACHAT_CREDENTIALS, DATABASE_URL
alembic upgrade head            # таблицы
python -m app.main              # бот + Mini App на :8080
pytest -q                       # тесты (LLM замокан)
python -m scripts.eval_phrases  # проверочные фразы на живом GigaChat
```

## Деплой

На сервере с Docker:

```bash
git clone https://github.com/NIZHEGORODTSY/GORKY_CODE.git && cd GORKY_CODE
# положить .env с прод-настройками (POSTGRES_*, BOT_TOKEN, GIGACHAT_CREDENTIALS, DATABASE_URL с хостом db)
./scripts/deploy.sh             # git pull + docker compose: db (PostgreSQL 16) + bot; миграции — при старте
```

- **HTTPS для Mini App и подписки на календарь:** `WEBAPP_DOMAIN=<домен>` в `.env`. Если порты 80/443 свободны —
  поднимется Caddy с сертификатом Let's Encrypt; если на сервере уже есть nginx — `REVERSE_PROXY=nginx`
  и конфиг `deploy/nginx-gorky.conf` + `certbot --nginx -d <домен>`.
- **Хостинг блокирует Telegram:** `python3 scripts/vless_to_xray.py '<VPN-подписка>'` → `TELEGRAM_PROXY=socks5://xray:1080`
  — через прокси ходит только Telegram, GigaChat и база — напрямую.
- **База с компьютера:** `ssh -N -L 5433:127.0.0.1:5433 root@<сервер>` и pgAdmin на `localhost:5433`.

# Горький — голосовой планировщик

Telegram-бот, который по свободной речи (голосом или текстом) создаёт задачи, напоминания и встречи,
показывает планы на период и находит старые записи по смыслу.

**Бот: [@gorky_audio_bot](https://t.me/gorky_audio_bot)**

Для проверки в меню бота есть «📥 Демо-данные из задания» — загружает 1000 записей из CSV тестового задания.

## Функционал

**Основное (по ТЗ)**
- Создание задачи или напоминания: «Напомни завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт»
- Создание встречи: «В четверг в 11 у меня встреча с дизайнером»
- Список задач и встреч за период: «Что у меня сегодня?», «Что запланировано на эту неделю?»
- Поиск старых записей по смыслу: «Найди задачу про презентацию», «Когда у меня была встреча с Иваном?»
- Относительные даты: сегодня, завтра, в пятницу, через два часа, на следующей неделе
- Уточняющие вопросы: «Поставь встречу с Иваном завтра» → «На какое время поставить встречу?»

**Дополнительно**
- Перенос, переименование, выполнение и удаление голосом, в том числе по контексту («перенеси её на пятницу»)
- Предупреждение о пересекающихся встречах
- Повторяющиеся записи: «Каждый понедельник в 10 планёрка»
- Бот сам присылает напоминания; о встречах — заранее (время настраивается)
- Утренняя сводка, часовой пояс, голосовые ответы — в настройках
- Mini App-календарь внутри Telegram и подписка на календарь телефона (iPhone / Google)
- Несколько пользователей: у каждого аккаунта Telegram свои данные

## Стек

- Бот: Python 3.12, aiogram 3
- LLM: GigaChat-3-Pro — понимание запроса через вызов функций, распознавание голосовых
- Озвучка ответов: edge-tts
- БД: PostgreSQL 16, SQLAlchemy 2 (async), миграции Alembic
- Поиск: полнотекстовый поиск Postgres с русской морфологией; если ничего не найдено — GigaChat выбирает подходящие записи
- Mini App: aiohttp + HTML/JS без фреймворков
- Деплой: Docker Compose на VPS

## Архитектура

Голосовое → распознавание (GigaChat) → текст → GigaChat выбирает функцию и заполняет аргументы →
код проверяет аргументы и выполняет действие с базой → ответ текстом и голосом.

Модель не пишет в базу сама: она только выбирает действие (`create_event`, `list_events`, `search_events`,
`update_event`, `complete_event`, `delete_event`, `update_settings`). Даты по словам «завтра», «в четверг»,
«через 2 часа» считает код, а не модель.

## Структура

```
app/
  main.py          точка входа: бот, фоновые напоминания, веб-сервер Mini App
  config.py        настройки из .env
  bot/             Telegram: обработчики, клавиатуры, панель-меню, напоминания и сводка

  llm/             клиент GigaChat и описания функций для модели
  speech/          распознавание (GigaChat) и озвучка (edge-tts)
  core/            даты, повторы, оформление ответов, экспорт в календарь, демо-данные
  storage/         таблицы и запросы к базе
  search/          поиск по смыслу через GigaChat
  webapp/          Mini App-календарь и подписка на календарь
migrations/        миграции базы
tests/             тесты (pytest)
scripts/           деплой, проверка понимания фраз, прокси для Telegram
assets/            картинки бота, CSV из тестового задания
```

## Запуск

Нужны Python 3.12+, PostgreSQL 16, токен бота от @BotFather и ключ GigaChat API.

```bash
git clone https://github.com/NIZHEGORODTSY/GORKY_CODE.git && cd GORKY_CODE
python -m venv .venv && .venv/Scripts/pip install -r requirements-dev.txt
cp .env.example .env      # заполнить BOT_TOKEN, GIGACHAT_CREDENTIALS, DATABASE_URL
alembic upgrade head
python -m app.main
```

Тесты: `pytest -q`. Проверка понимания фраз на живом GigaChat: `python -m scripts.eval_phrases`.

### На сервере

Нужен Docker с Compose. В `.env` — прод-настройки, в `DATABASE_URL` хост `db`.

```bash
./scripts/deploy.sh
```

Скрипт обновляет код и поднимает PostgreSQL и бота; миграции применяются при старте.
Для Mini App нужен HTTPS: в `.env` указать `WEBAPP_DOMAIN`. Если хостинг блокирует Telegram —
`scripts/vless_to_xray.py` и `TELEGRAM_PROXY=socks5://xray:1080`.

## Принятые решения

- Telegram-бот вместо веб-страницы: голосовые сообщения есть сразу, ссылка на бота — готовый прототип.
- GigaChat выбран по замерам на фразах из ТЗ: 35 из 37 правильных ответов.
- Даты считает код — модель ошибалась в днях недели.
- Поиск без платных эмбеддингов: полнотекстовый поиск + выбор подходящих записей через GigaChat.
- SaluteSpeech для физлиц закрыт, поэтому голос распознаёт GigaChat, а озвучивает edge-tts.
